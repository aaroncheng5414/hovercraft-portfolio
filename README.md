# Aaron Cheng's portfolio

A portfolio of embedded systems, mechanical design, computer vision, and interface work, tailored to creative technology at Hovercraft.

The site uses plain HTML, CSS, and JavaScript. It includes a door that opens on scroll, expandable project notes, and a keyboard-accessible signal sketch with optional motion. It respects reduced-motion preferences.

## Preview

Serve this directory with any static web server. With Python installed, run `python -m http.server 4173` and open `http://localhost:4173`.

## Publish with GitHub Pages

In the repository's Settings → Pages, choose **Deploy from a branch**, select **main** and **/ (root)**, and save. All asset links are relative, so the site works under a repository path. The `.nojekyll` file keeps the files unprocessed.

## Edit

- `index.html` contains the project descriptions and page structure
- `styles.css` contains the responsive layout and visual design
- `script.js` controls the door and signal sketch
- `assets/` contains the original illustrations, team prototype images, and a render of the custom headset parts

Concept illustrations are labeled on the page. Portal is work in progress. Employer work is described at a high level. Private project code, internal documents, and source research notes are not included.
